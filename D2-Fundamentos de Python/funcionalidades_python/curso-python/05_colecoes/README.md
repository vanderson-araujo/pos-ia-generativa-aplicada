# 05 - Colecoes

## Objetivo

Aprender a guardar varios valores em uma unica variavel.

## Conceitos abordados

- `list`
- `tuple`
- `dict`
- `set`
- percorrer colecoes com `for`

## Como executar

```bash
python 01_list.py
python 03_dict.py
```

## Observacoes

Comparacoes com Java:

- `list` em Python lembra `ArrayList`.
- `dict` lembra `Map`.
- `set` lembra `Set`.
