# 07 - Arquivos

## Objetivo

Aprender a ler e gravar informacoes em arquivos.

## Conceitos abordados

- abrir arquivos com `open()`
- ler texto
- escrever texto
- CSV
- JSON

## Como executar

```bash
python 01_ler_arquivo.py
python 02_escrever_arquivo.py
python 03_csv.py
python 04_json.py
```

## Observacoes

Os exemplos criam arquivos pequenos na propria pasta para facilitar o estudo.
