# 03 - Repeticao

## Objetivo

Aprender a repetir comandos sem copiar e colar codigo varias vezes.

## Conceitos abordados

- `while`
- `for`
- `range()`
- `break`
- `continue`
- `pass`

## Como executar

```bash
python 01_while.py
python 02_for.py
```

## Observacoes

Loops sao muito usados para percorrer listas, processar arquivos, contar itens e
repetir tarefas de automacao.
