# 09 - Orientacao a Objetos

## Objetivo

Entender como representar elementos do mundo real usando classes e objetos.

## Conceitos abordados

- classe
- objeto
- atributos
- metodos
- construtor
- encapsulamento
- heranca
- polimorfismo

## Como executar

```bash
python 01_classe_objeto.py
python 06_polimorfismo.py
```

## Observacoes

Orientacao a objetos ajuda a organizar dados e comportamentos que pertencem ao
mesmo conceito, como Cliente, Produto, Pedido ou Conta.
