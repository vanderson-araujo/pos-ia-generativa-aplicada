# 10 - Recursos Modernos

## Objetivo

Conhecer recursos atuais do Python que ajudam a escrever codigo mais expressivo.

## Conceitos abordados

- `dataclass`
- `Enum`
- anotacoes de tipo
- `Literal`
- `Optional`
- `namedtuple`

## Como executar

```bash
python 01_dataclass.py
python 03_typing.py
```

## Observacoes

As anotacoes de tipo ajudam ferramentas e pessoas a entenderem o codigo. Elas
nao sao obrigatorias em tempo de execucao.
