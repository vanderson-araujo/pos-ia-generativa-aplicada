# 06 - Modulos e Imports

## Objetivo

Aprender a dividir o codigo em varios arquivos e reutilizar funcoes.

## Conceitos abordados

- `import`
- `from ... import ...`
- organizacao por arquivos
- pacote com pasta e `__init__.py`
- atividade Hamburgueria Divertida

## Como executar

Na pasta `06_modulos`, rode:

```bash
python main.py
```

Para a atividade:

```bash
cd hamburgueria
python main.py
```

## Observacoes

Modulos ajudam a evitar arquivos gigantes. Pense neles como gavetas: cada uma
guarda um tipo de codigo.
