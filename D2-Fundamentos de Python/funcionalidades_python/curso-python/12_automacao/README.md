# 12 - Automacao

## Objetivo

Ver exemplos de tarefas que Python pode automatizar no dia a dia.

## Conceitos abordados

- organizar arquivos
- ler planilhas
- gerar PDF
- preparar impressao de documento
- consumir API

## Como executar

```bash
python 01_organizar_arquivos.py
python 05_consumir_api.py
```

Alguns exemplos usam bibliotecas externas:

```bash
pip install openpyxl reportlab requests
```

## Observacoes

Automacao deve ser testada primeiro em pastas de exemplo, nunca diretamente em
pastas importantes sem conferir o comportamento.
