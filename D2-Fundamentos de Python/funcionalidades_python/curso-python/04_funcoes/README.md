# 04 - Funcoes

## Objetivo

Aprender a organizar codigo em blocos reutilizaveis.

## Conceitos abordados

- criacao de funcoes com `def`
- parametros
- retorno com `return`
- multiplos retornos
- parametros opcionais
- argumentos nomeados
- escopo de variaveis locais

## Como executar

```bash
python 01_funcao_simples.py
python 03_retorno.py
```

## Observacoes

Funcoes ajudam a evitar repeticao e deixam o codigo mais facil de testar e
explicar.
