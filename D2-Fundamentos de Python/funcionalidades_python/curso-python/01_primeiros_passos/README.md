# 01 - Primeiros Passos

## Objetivo

Aprender a executar comandos basicos em Python, mostrar mensagens na tela,
receber dados, criar variaveis, entender tipos basicos e converter valores.

## Conceitos abordados

- `print()`
- `input()`
- variaveis
- `str`, `int`, `float`, `bool`
- operadores aritmeticos
- operadores compostos como `+=`, `-=`, `*=`
- conversao de tipos
- escape de strings

## Como executar

```bash
python 01_print.py
python 02_input.py
python 03_variaveis.py
```

## Observacoes

Em Java, voce usaria `System.out.println()`. Em Python, usamos `print()`, que e
mais curto e direto.
