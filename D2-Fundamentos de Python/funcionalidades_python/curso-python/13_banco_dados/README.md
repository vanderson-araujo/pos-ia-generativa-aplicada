# 13 - Banco de Dados

## Objetivo

Aprender operacoes basicas com SQLite, um banco de dados simples que ja vem com
Python.

## Conceitos abordados

- conexao
- criar tabela
- inserir
- selecionar
- atualizar
- deletar

## Como executar

Execute na ordem:

```bash
python 01_conexao_sqlite.py
python 02_criar_tabela.py
python 03_insert.py
python 04_select.py
python 05_update.py
python 06_delete.py
```

## Observacoes

SQLite salva os dados em um arquivo local. Neste modulo, o arquivo criado sera
`loja.db`.
