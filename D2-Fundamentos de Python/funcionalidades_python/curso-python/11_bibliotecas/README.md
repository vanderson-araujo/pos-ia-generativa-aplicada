# 11 - Bibliotecas

## Objetivo

Entender como instalar e usar bibliotecas externas.

## Conceitos abordados

- `pip`
- ambiente virtual com `venv`
- `requirements.txt`
- exemplos com `requests`, `pandas` e `Pillow`

## Como executar

Leia primeiro:

```bash
type 01_pip.txt
type 02_venv.txt
type 03_requirements.txt
```

Depois instale as dependencias desejadas:

```bash
pip install requests pandas pillow
```

Execute exemplos:

```bash
python exemplos/requests_exemplo.py
```

## Observacoes

Nos modulos iniciais evitamos bibliotecas externas. Aqui elas aparecem porque
sao comuns em projetos reais.
