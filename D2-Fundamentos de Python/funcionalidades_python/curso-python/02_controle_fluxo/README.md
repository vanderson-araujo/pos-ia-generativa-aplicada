# 02 - Controle de Fluxo

## Objetivo

Aprender a tomar decisoes no codigo. Programas reais quase sempre precisam
executar caminhos diferentes dependendo de uma condicao.

## Conceitos abordados

- `if`
- `else`
- `elif`
- operadores logicos `and`, `or`, `not`
- operador ternario
- `match case`

## Como executar

```bash
python 01_if_else.py
python 05_match_case.py
```

## Observacoes

Python usa indentacao, ou seja, espacos no inicio da linha, para indicar quais
comandos pertencem ao `if`, `else`, `for`, funcoes e outros blocos.
