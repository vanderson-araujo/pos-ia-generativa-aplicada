# Curso Python para Iniciantes

Este repositorio foi criado para estudar Python do zero, com exemplos simples,
comentados e proximos do dia a dia. A ideia e que cada arquivo possa ser aberto,
lido e executado separadamente.

Python e uma linguagem muito usada para automacao, dados, APIs, inteligencia
artificial, scripts e sistemas web. Aqui usamos Python 3.11 ou superior.

## Pre-requisitos

- Ter curiosidade e vontade de praticar.
- Ter o Python 3.11+ instalado.
- Usar um editor de codigo, como VS Code, PyCharm ou o proprio terminal.

## Como instalar Python

1. Acesse https://www.python.org/downloads/
2. Baixe a versao mais recente para seu sistema operacional.
3. No Windows, marque a opcao `Add Python to PATH` durante a instalacao.
4. Confira no terminal:

```bash
python --version
```

Em alguns computadores o comando pode ser:

```bash
python3 --version
```

## Como executar arquivos `.py`

Entre na pasta do exemplo e rode:

```bash
python nome_do_arquivo.py
```

Exemplo:

```bash
cd 01_primeiros_passos
python 01_print.py
```

## Observacoes importantes

- Os primeiros modulos usam apenas recursos nativos do Python.
- Quando aparecer uma biblioteca externa, o README do modulo explica como instalar.
- Anotacoes de tipo, como `nome: str`, ajudam a documentar o codigo, mas Python
  nao obriga esses tipos em tempo de execucao.
- Em alguns pontos ha comparacoes com Java para ajudar quem ja viu essa linguagem.
