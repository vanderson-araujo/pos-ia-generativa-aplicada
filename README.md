# pos-ia-generativa-aplicada

Este repositório reúne códigos de estudo e projetos referentes às atividades das disciplinas da pós-graduação `IA Generativa Aplicada` da UTFPR.

O objetivo é organizar notebooks, scripts e conjuntos de dados usados em cada etapa do curso, permitindo revisar os conceitos e reproduzir os experimentos com facilidade.

## Estrutura do repositório

- `09-05-classificacao/`: exercícios e notebooks de classificação, incluindo o fluxo de `arvore_decisao.ipynb`.
- `09-05-classificacao/data/`: conjuntos de dados utilizados para os exemplos de classificação.
- `09-05-classificacao/notebooks/`: notebooks Jupyter com códigos comentados e análises de aprendizado de máquina.

## Estrutura de uso

Cada atividade inclui seu próprio README ou instruções internas para guiar a execução do notebook e as dependências específicas.

## Finalidade

Este repositório é uma coleção de estudos para apoiar o aprendizado em IA Generativa Aplicada e documentar as atividades realizadas durante a pós-graduação.
